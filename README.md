# entry-u-0xkianno-one-word-first-thought-106abaf8 — One Word, First Thought

One word for make.fun's "One Word, First Thought" bounty: the most
interesting word, the first that comes to mind.

> petrichor

Why it should win: it is surprising (most readers have never met
the word), vivid and specific (it names one exact smell — rain on
dry earth — and calls up the image and the feeling in nine
letters), and it carries a quiet wit in its sound, petrichor
sounding like the rain it names. Not a filler word, not the trendy
pick, and chosen rather than generic. One word, 9 characters.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13 standard library only, no network, no
randomness) writes the word to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(falling back to `$MAKEFUN_OUTPUT`, then `/output`) and asserts the
competition's gate itself: exactly one word, 1–24 characters. The
word is a fixed string, so two runs produce identical bytes.
